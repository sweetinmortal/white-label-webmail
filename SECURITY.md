# Seguridad

No abras un issue público para reportar una vulnerabilidad.

Usa **Security → Report a vulnerability** en GitHub para abrir un aviso privado. Si no tienes acceso a esa opción, escribe a `asijerson@gmail.com` con:

- versión o commit afectado;
- descripción del impacto;
- pasos mínimos para reproducirlo;
- cualquier mitigación que hayas identificado.

No incluyas datos reales de clientes, credenciales ni correos completos. Confirmaré la recepción y coordinaré la corrección y la divulgación.

## Alcance

Este repositorio contiene el motor y la plantilla. Cada instalación es responsable de su propia cuenta de Cloudflare, su configuración, sus secretos y sus datos. Los problemas de una instalación concreta deben reportarse por el canal privado de esa instalación.
